# Still — установка на другом ПК

## Что скачать

Откройте https://github.com/insultikkk/Portfolio/releases/tag/v0.1.0 и раздел **Assets**.

- `Still-v0.1.0-Windows-x64.zip` — полный набор: Windows-установщик, расширение и эта инструкция.
- `Still-v0.1.0-Chrome-Edge-extension.zip` — только расширение, если Still уже установлен.
- `SHA256SUMS.txt` — контрольные суммы двух архивов.

Если файлов пока нет, [проверьте сборку](https://github.com/insultikkk/Portfolio/actions/workflows/windows.yml). Исходники **Source code (zip)** не содержат готового установщика.

## Требования

Windows 10/11 **x64**, Chrome или Edge версии 116+ и Интернет для первой установки, SoundCloud и получения текстов. ARM64-сборка и другие ОС пока не предусмотрены. Для воспроизведения сохранённого текста Интернет не нужен. Node.js, Rust и Visual Studio для готовой версии не требуются.

## 1. Установить приложение

1. Распакуйте `Still-v0.1.0-Windows-x64.zip` в отдельную папку.
2. Запустите `Still-Setup-0.1.0-x64.exe`. Установка выполняется для текущего пользователя.
3. Запустите **Still Live Lyrics**. При отсутствии WebView2 установщик может запросить его загрузку с серверов Microsoft.

Сборка предварительная и **не подписана цифровой подписью**. Если Windows сообщает о неизвестном издателе, проверьте источник файла и контрольную сумму. Не отключайте антивирус или SmartScreen. Непонятное предупреждение — повод остановиться и проверить файл.

Проверка скачанного архива в PowerShell:

```powershell
Get-FileHash .\Still-v0.1.0-Windows-x64.zip -Algorithm SHA256
```

Сравните результат с `SHA256SUMS.txt` из того же релиза. Внутри полного архива также есть `CONTENTS-SHA256.txt` с суммами установщика и файлов расширения. Контрольная сумма проверяет целостность, но не заменяет подпись издателя.

## 2. Добавить расширение

1. Chrome: откройте `chrome://extensions`. Edge: `edge://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `extension` из полного архива. В ней должен лежать `manifest.json`.
4. Не удаляйте и не перемещайте эту папку, пока расширение используется. При необходимости закрепите Still рядом с адресной строкой.

Для отдельного архива расширения сначала распакуйте его в постоянную папку и выберите именно её.

## 3. Соединить с SoundCloud

1. В Still откройте **Подключение**, получите и скопируйте токен сопряжения.
2. Откройте popup расширения, вставьте токен и нажмите **Подключить приложение**.
3. Обновите вкладку SoundCloud и включите песню. Появятся название, исполнитель и текст, если он доступен в LRCLIB или кэше.
4. Если найдено несколько версий записи, выберите подходящую в настройках Still.

Токен новый на каждом компьютере: старый токен с другого ПК не нужен. Музыкальные пароли и ключи API не запрашиваются. Сейчас поддерживается SoundCloud; подключения Spotify и Яндекс Музыки ещё не реализованы.

## Горячие клавиши

| Клавиши      | Действие                                     |
| ------------ | -------------------------------------------- |
| `Ctrl+Alt+L` | Скрыть / показать карточку                   |
| `Ctrl+Alt+E` | Перемещать карточку / снова пропускать клики |

Настройки и выход доступны через значок Still в трее. Закрытие настроек не завершает приложение. Для полного завершения выберите **Выйти** в трее.

## Если текста нет

Откройте **Локальный ИИ** → **Подготовить локальную модель**. Многоязычная Whisper Small скачивается один раз (~466 МиБ), проверяется и квантуется на компьютере. Затем на играющей вкладке нажмите в расширении **Распознавать эту вкладку**.

Обрабатывается только звук выбранной вкладки. Микрофон и общий звук компьютера не используются. Первый текст появляется с задержкой, может содержать ошибки и отмечается как приблизительный. После прослушивания сохраняются строки и реальные интервалы покрытия, а не аудиозапись.

## Важно о первой версии

Это **personal preview**, а не подписанный стабильный выпуск. Автоматические проверки и сборка не заменяют ручную проверку на Windows: закрепление окна, Alt+Tab, Chrome/Edge, звук и русское/английское распознавание. Полный список — в `docs/validation.md` репозитория.

Корпоративная политика браузера может запрещать распакованные расширения. Не обходите её; установка потребует разрешения администратора. Поверх UAC, защищённого рабочего стола и эксклюзивного fullscreen работа не гарантируется.
