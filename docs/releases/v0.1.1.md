# Still 0.1.1

Предварительный выпуск для Windows 10/11 x64 и SoundCloud в Chrome и Edge.

- `Still-Setup-0.1.1-x64.exe` устанавливает приложение для текущего пользователя.
- `Still-v0.1.1-Chrome-Edge-extension.zip` содержит расширение.
- `Still-v0.1.1-Windows-x64.zip` содержит установщик, расширение и инструкцию.
- `SHA256SUMS.txt` содержит контрольные суммы этих файлов.

Выпуск восстанавливает сборку Whisper под Windows и чтение актуальных ответов LRCLIB. Оверлей учитывает паузу и положение ползунка, когда часы медиаплеера SoundCloud запаздывают. Чёрно-оранжево-белая палитра и крупный текст сохранены.

Установите Still, распакуйте ZIP расширения и выберите папку с `manifest.json` через «Загрузить распакованное расширение» на странице `chrome://extensions` или `edge://extensions`. Скопируйте токен из раздела «Подключение» в popup расширения. Обновите вкладку SoundCloud и включите трек.

Установщик без цифровой подписи. Для локального распознавания нужно отдельно подготовить модель в приложении.
