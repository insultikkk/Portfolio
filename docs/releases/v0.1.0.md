# Still 0.1.0 — personal preview

Первая предварительная версия оверлея Live Lyrics для Windows 10/11 x64 и SoundCloud в Chrome/Edge.

## Скачать

- **Still-v0.1.0-Windows-x64.zip** — установщик + расширение + инструкция. Это основной архив для другого ПК.
- **Still-v0.1.0-Chrome-Edge-extension.zip** — только расширение.
- **SHA256SUMS.txt** — SHA-256 архивов.

Распакуйте основной архив, запустите `Still-Setup-0.1.0-x64.exe`, затем загрузите папку `extension` в браузер через «Загрузить распакованное расширение». Подробности — в `INSTALL-RU.md` внутри архива и [инструкции репозитория](https://github.com/insultikkk/Portfolio/blob/main/docs/windows-install.md).

## Возможности

- Матовый оверлей: чёрный, белый и оранжевая подсветка слов.
- LRCLIB, построчные/доступные пословные тайминги, выбор версии записи и кэш SQLite.
- Локальный Whisper Small в отдельном процессе; только выбранная вкладка, без микрофона и облачного ASR.
- Горячие клавиши, трей, прозрачность, размер и поправка синхронизации.
- Отмена незавершённого запуска захвата, сохранение последнего фрагмента и очистка плеера после закрытия вкладки.

## Ограничения

Установщик **без цифровой подписи**, поэтому возможно предупреждение SmartScreen. Проверяйте источник и SHA-256; не отключайте защиту системы. Модель Whisper скачивается отдельно при включении ИИ и не входит в архив. Spotify и Яндекс Музыка пока не подключены.

Сборка предварительная: успешные автоматические проверки не подтверждают реальное поведение окон и tabCapture на каждом Windows-ПК. Ручная проверка Windows/Chrome/Edge ещё необходима. Распознанный ИИ-текст приблизительный; качество вокального распознавания не приравнивается к готовому авторскому тексту.
